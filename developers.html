Quickstart

Three steps to connect.

01

Create an API key

Generate a live key in your dashboard and keep it on your server. Never ship it to the browser.

Open dashboard →
02

Send confirmed payments

POST each logical transaction with a unique Idempotency-Key. Retrying the same key is safe.

See endpoint →
03

Listen for changes

Register a webhook endpoint and receive signed transaction lifecycle events.

Configure →
Security rule: live API keys belong on your backend. Webhook signing secrets are shown only when an endpoint is created.

Transactions API

Create a transaction.

When your payment provider confirms a payment, send the transaction to ValoraTap. A receipt and public verification path are returned.

Request
POST https://pddjualtnhgmplampucn.supabase.co/functions/v1/transactions
Authorization: Bearer sk_live_xxxxxxxxx
Content-Type: application/json
Idempotency-Key: order_2026_00124

{
  "amount": 1250.00,
  "currency": "ZAR",
  "payment_method": "card",
  "customer": { "name": "John Doe", "email": "john@example.com", "phone": "+27820000000" },
  "description": "Towing service",
  "reference": "MOS-2026-00124"
}
Response
{
  "success": true,
  "replayed": false,
  "receipt": {
    "id": "uuid",
    "receipt_no": "VT-000124",
    "verification_hash": "sha256...",
    "verification_path": "/verify.html?id=uuid"
  },
  "protocol_version": "1.0"
}
