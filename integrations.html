Node.js SDK

Simple enough to drop into a backend.

The SDK is intentionally thin: it wraps the public ValoraTap HTTP contract and never exposes a secret to the browser.

Install / import
import { ValoraTap } from './sdk/valoratap.js';

const vt = new ValoraTap({
  apiKey: process.env.VALORATAP_API_KEY
});
Create transaction
const result = await vt.transactions.create({
  amount: 1250.00,
  currency: 'ZAR',
  payment_method: 'card',
  customer: { name: 'John Doe' },
  description: 'Towing service',
  reference: 'MOS-2026-00124',
  idempotencyKey: 'order_MOS_2026_00124'
});

console.log(result.receipt.receipt_no);
Important: the SDK is for server-side code only. Never place sk_live_... in browser JavaScript, mobile apps or public source code.
